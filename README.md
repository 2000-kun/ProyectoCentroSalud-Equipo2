# Proyecto Final CentroSalud - Equipo de 2 personas

Aplicación de consola en Java (Estructura de datos y laboratorio).
Documento: Actividad #5 - Proyecto Final.

## Integrantes

| Nombre | Rol | Módulos |
|---|---|---|
| Integrante 1 | POO + Listas | `Paciente`, `PacienteEPS`, `PacienteSISBEN`, `Nodo`, `Lista` |
| Integrante 2 | ABB + Cola/Pila | `NodoArbol`, `Arbol`, `Cita`, `Cola`, `Pila` |
| Ambos | Integración | `CentroSalud.java` (menú) y CSV de pacientes |

## Reglas del equipo

1. Cada quien edita **solo sus archivos**.
2. Antes de programar, acuerdan las firmas de los métodos (contrato).
3. `CentroSalud.java` lo integra una sola persona al final.
4. Nada se sube sin probarlo primero (main de prueba propio).
5. Revisión cruzada del código de otro antes de entregar.

## Cómo montarlo en NetBeans

1. File → New Project → Java with Ant → Java Application (desmarcar *Create Main Class*).
2. Pegar los `.java` en `src` cuando existan.
3. Clean and Build → Run (F6).
